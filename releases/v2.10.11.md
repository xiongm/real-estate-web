
## What's Changed
- **Enhanced User Feedback:** Added toast notifications for successful document deletions in the Admin portal. Notifications now include the specific document name for single-item deletions.
- **Upload Configuration:** Reduced the default file upload size limit from 20MB to 10MB to better manage resource usage.
- **Bug Fixes:** Resolved an import issue in the upload library and improved error handling during deletion operations.

## Technical Details
- Modified `web/app/admin/page.tsx` to implement `showToast` calls with dynamic messages based on the operation context.
- Updated `web/lib/upload.ts` to enforce the new 10MB limit and removed unused types import.
- Verified changes with E2E tests (`npm run test:e2e`).
