
## What's Changed
- **Performance Optimization for China:** Implemented **Resumable Chunked Uploads**. Large requests are now split into small chunks (512KB) that are uploaded sequentially. This drastically improves upload reliability and speed for users in China or on unstable connections, as individual chunks are retried upon failure instead of restarting the entire upload.
- **Backend Infrastructure:** Added `chunked_uploads` router and updated `storage.py` to support multipart object composition in Minio/S3.
- **Frontend Agility:** Replaced the document upload logic in the Admin portal with the new chunked uploader.

## Technical Details
- New API endpoints: `/api/uploads/init`, `/api/uploads/chunk`, `/api/uploads/complete`.
- Frontend: `chunkedUpload` utility with retry logic.
- Backend: Uses `put_object` for chunks and `compose_object` for final assembly.
