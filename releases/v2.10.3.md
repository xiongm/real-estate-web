# v2.10.3

### 🚀 Enhancements
- **File Upload Hardening**:
    - **Progress Bar**: Visual feedback during document uploads in Admin and Request Sign pages.
    - **Size Limit**: Enforced 20MB file size limit (configurable via `NEXT_PUBLIC_MAX_UPLOAD_SIZE_MB`).
    - **Timeout**: Added 60s timeout for uploads (configurable via `NEXT_PUBLIC_UPLOAD_TIMEOUT_MS`).
    - **Toasts**: Added success/failure notifications for upload actions.

### 🐛 Bug Fixes
- **Type Safety**: Fixed `investorForm` and `SignerForm` type definitions in `request-sign` page.
- **Cross-Browser**: Fixed CSS border shorthand warning in Firefox for checkbox fields.
