# Release v2.10.9

## Bug Fixes & Improvements

- **Request Sign Progress Bar**: Updated the progress bar on the "Request Signatures" page to span the full width of the upload container, matching the Admin interface for better consistency.
- **Improved Toast Notifications**: Document upload notifications (in both Admin and Request Sign pages) now include the filename of the uploaded document for clearer confirmation (e.g., `Document "contract.pdf" uploaded successfully`).
