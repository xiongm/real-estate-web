# Release v2.11.0

## Summary
This release focuses on hardening the large file upload capability and refreshing the Admin Dashboard UI.

### Features
- **Admin Dashboard UI**: Updated the "Documents" tab with a new, full-width "Upload New Documents" card design.
- **Enhanced File Uploads**: Replaced S3 `compose_object` logic with a streaming approach to bypass the 5MB minimum part size limit, enabling reliable upload of files of any size with small chunks.

### Bug Fixes
- **Chunked Uploads**: Fixed `Internal Server Error` (500) and `404 Not Found` errors during the upload initialization and completion phases.
- **Backend Stability**: Restored missing API router code (`chunked_uploads.py`) that was causing admin login and upload failures. Added missing `datetime` imports.
- **Upload Reliability**: Fixed `TypeError` in `put_temp_chunk` arguments.

### Testing
- Added comprehensive unit tests (`api/tests/test_chunked_uploads.py`) covering the full upload lifecycle for both Document and ProjectFile resource types.
