# Release v2.11.1

## Summary
Bug fix release to improve navigation UX between Admin and Request Sign pages.

### Fixes
- **Back to Admin navigation**: Changed from full page reload (`<a href>`) to `history.back()` for faster return navigation
- **Tab persistence**: Admin page now remembers selected tab (Signatures/Documents/etc.) when returning from Request Sign via sessionStorage

### Documentation
- Updated `docs/admin-ui-behaviors.md` with UI State Persistence guidelines
- Added `.agent/workflows/ui-state-persistence.md` workflow for consistent implementation
