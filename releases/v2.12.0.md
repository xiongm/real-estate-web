# Release v2.12.0

## Summary

### New Feature: Signer Email Update & Resend

Admins can now update a signer's email/name and resend signing links after an envelope has been sent.

**API:**
- `PATCH /api/envelopes/{id}/signers/{signer_id}` - Update signer details
- `POST /api/envelopes/{id}/signers/{signer_id}/resend` - Resend signing link email

**Admin UI:**
- New "Edit" button for pending signers - inline editing of name/email
- New "Resend" button - sends reminder email with signing link
- Seamless state updates without page refresh

## Notes
- Only works for pending signers on sent envelopes
- Updating signer email does NOT update the investor profile
- Existing signing links remain valid after email change
