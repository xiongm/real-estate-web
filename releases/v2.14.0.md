# Release v2.14.0

## Summary
- **Download Unfinished Document Snapshots**: Admins can now download the current version of a document while it is still being signed. The document link for in-progress envelopes now points to a snapshot PDF that includes all signatures and field values collected up to the current moment.
- **Backend Snapshot Generation**: Integrated PDF sealing logic into a new backend endpoint to dynamically generate snapshot PDFs.

## Checks
- [x] API tests (including new snapshot download tests)
- [x] Web e2e tests
- [ ] Manual smoke

## Notes
- No special deployment steps. The snapshot functionality is handled by the existing PDF sealing infrastructure.
