# Release v2.14.2

## Summary
- Added initials controls to envelope preparation and required separate drawn or uploaded initials when initials fields are present.
- Improved SMTP reliability with IPv4 retries and timeouts, and only mark envelopes sent after email delivery succeeds.
- Added an opt-in host API Compose override for environments with unreliable Docker container egress while preserving Docker-first defaults.

## Checks
- [x] API tests
- [x] Web production build
- [ ] Web e2e tests
- [x] Manual smoke

## Notes
- Standard development remains `docker compose up --build`.
- The host API workaround is opt-in through `docker-compose.host-api.yml` and `scripts/run-host-api.py`.
- Web e2e was not run because this host is missing Playwright browser system libraries.
