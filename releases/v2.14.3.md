# Release v2.14.3

## Summary
- Added save, autosave, resume, and delete workflows for draft signature requests.
- Restored draft fields, signer assignments, document state, and request content when editing.
- Matched draft cards to the existing signature packet design with consistent hover and keyboard-focus feedback.
- Added a layout-matched loading state to prevent the upload interface from flashing while drafts load.
- Improved draft accessibility with responsive loading layouts, reduced-motion support, and announced save status.
- Prevented failed send attempts from partially updating incomplete drafts.
