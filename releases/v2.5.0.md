## v2.5.0 Release Notes

- Audit retention window introduced (default 30 days):
  - New env var `AUDIT_RETENTION_DAYS` (added to `.env`/`.env.example` and `docker-compose.yml`).
  - API startup prunes `audit_events` older than the retention window; applies retention cutoff to audit queries/exports and returns `retention_days` to the UI.
  - Frontend audit tab displays the retention window and supports date filters/pagination totals.
- Investor edit flow now refetches investors after a save to keep KPIs in sync; regression test added for KPI refresh.

Deployment impact:
- **DB migration**: None. Pruning removes old `audit_events` on API startup.
- **App restart**: Required for new env var and pruning to take effect.
- **Periodic pruning**: Not scheduled yet; pruning only at API startup (add a daily worker job later if needed).
