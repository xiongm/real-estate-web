# Release v2.7.0

## Summary
- Added AI document summary pipeline: server-side OpenAI generation (configurable model/timeout/char limit), persisted on envelopes with manual edit support.
- New UI for summaries: request-sign confirmation toggle + disabled textarea when AI enabled, blocking send overlay with status steps, signer "AI summary" card, admin inline-edit textarea.
- API additions: summary included in signing/admin payloads and PATCH `/api/envelopes/{id}/summary`; fail-soft sending when AI generation times out or fails.
- Ops/tooling: docker-compose gains DOC summary env vars; `scripts/use-release.sh` now syncs `.env` APP_VERSION via `release-version.sh`.
- Tests: API summary unit coverage; datetime partial-entry Playwright test skipped on Firefox/WebKit due to flake.

## Notes
- New envs (set in `.env`/prod): `OPENAI_API_KEY`, `ENABLE_DOC_SUMMARY` (default true), `DOC_SUMMARY_MODEL`, `DOC_SUMMARY_CHAR_LIMIT` (default 300), `DOC_SUMMARY_TIMEOUT`.
- Summary generation is non-blocking; envelopes still send if AI fails. Fallback to secondary model when primary errors.
- Run `./release-version.sh` (auto-run by use-release.sh) to keep APP_VERSION in sync with latest tag.
